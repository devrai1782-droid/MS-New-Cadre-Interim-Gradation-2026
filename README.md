# 📊 MS New Cadre Interim Gradation List Portal

An optimized, web-based data management tool designed for the search, verification, and analysis of **Madhya Pradesh Teacher Gradation** data. 

### 🚀 Live Demo
**[View Live Portal Here](https://your-username.github.io/ms-gradation-2026/)**

---

## 🌟 Key Features
* **High-Capacity Processing:** Smoothly manages and displays datasets exceeding **1 Lakh (100,000) records** directly in the browser.
* **Advanced Search:** Real-time filtering by Name, Unique ID, or District.
* **Excel Integration:** Built-in logic for bulk importing data from Excel sheets.
* **Security & Protection:** * **Logic Obfuscation:** Source code is scrambled to protect administrative logic and data structures.
    * **Client-Side Integrity:** Custom validation protocols (e.g., 18-year age gap check for appointments).
* **Responsive UI:** A space-saving, compact layout optimized for both desktop and mobile use by field staff.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Professional Compact UI)
* **Logic:** JavaScript (ES6+)
* **Protection:** Professional Obfuscation & Minification
* **Hosting:** GitHub Pages

## 📂 Project Structure
* `index.html`: The core application (contains scrambled logic and minified styles for security).
* `data/`: (Optional) Folder for source datasets if kept separate.

## 📝 Usage for Staff
1.  Open the live link on any device.
2.  Use the **Search Bar** to find specific records by entering a 6-character Unique ID.
3.  View regional summaries via the built-in dashboard analytics.

## 🔒 Security Note
This repository uses **Code Obfuscation**. While the tool is open for public use/verification, the underlying JavaScript logic has been transformed into a non-human-readable format to prevent unauthorized tampering and to protect the integrity of the gradation calculation rules.
